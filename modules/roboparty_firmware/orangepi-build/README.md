## Quick Start

```bash
cd orangepi-build
./build.sh
```

Select board during build:

| Firmware | Board Selection |
|:--|:--|
| 01 | `robopi1` |
| 02 | `robopi2` |
| 03 | `robopi3` |

**Recommended Kernel Version**: `current`
